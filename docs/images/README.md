# Screenshot assets

README images use stable repository-relative paths:

- `beamcheck-main.png` — main BeamCheck window with the default example loaded
- `beamcheck-results.png` — result summary after calculating the same example
- `beamcheck-report.png` — optional PDF report preview for a future documentation update

Capture screenshots from the real packaged release candidate at a readable Windows display scale. Use the same non-project-specific example in every image, hide personal paths or data, and verify that each screenshot matches the released UI. Do not replace these files with conceptual mock-ups.
